# Before making this repository public

The repository remains private at the owner's request. Licensing is intentionally
undecided. Public visibility and licensing are separate decisions.

- Confirm original code authorship and any reused code requiring additional credit.
- Confirm that aggregate UDOT/RESCO/SUMO-derived results can be redistributed under
  the applicable source terms. No raw event exports or network assets are included.
- Choose a license for original code and document any separate third-party terms.
- Review README results, tradeoffs, and limitations for the target job application.
- Confirm that no confidential work, credentials, or personal local paths remain.
- Keep PROVENANCE.json linked to a committed main-project version.
- Check the Actions tab for passing offline tests before sharing the public link.

Attribution: Eclipse SUMO provides simulation/control interfaces; scikit-learn,
NumPy, and SciPy provide numerical/modeling tools. Historical reconstruction uses
UDOT ATSPM observations for March 19, 2026 and a RESCO-based network in the main
project. Detailed reconstruction methodology and evidence hierarchy remain in the
main archive. Personal research by MrM4yor, with AI-assisted development,
debugging, review, and documentation.
